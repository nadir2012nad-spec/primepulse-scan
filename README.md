# PrimePulse OPS Dynamic Scan — Vercel

URL format:
`https://your-domain.vercel.app/scan/solana/CONTRACT`

Example:
`/scan/solana/6mhnyjkwgfRcHQbwW5nTk1J6WDigjHoBz11sfsG4pump`

Deploy:
1. Upload this folder to a GitHub repo.
2. Import repo into Vercel.
3. Deploy.
4. Generate one permanent scan URL per detected contract.

No API keys required. It uses DexScreener public API client-side.
